## [TAB-A03-BR2_サーバー設定まで](#3)
1. チャレンジタッチの電源を落とす
2. ホームボタンと電源ボタンを同時に長押しする
4. 「工場出荷状態に戻しますか？」で「はい」を選択
5. 工場出荷状態に戻って電源が落ちる
6. 設定ボタンをタップする
7. Wi-Fiを押して自宅のWi-Fiと接続する
8. 設定画面に戻る
9. 一番下のタブレット情報を押す
10. ビルド番号を7回タップする
11. 開発者向けオプションを開く
12. USBデバッグをONにする
13. [](https://developer.android.com/tools/releases/platform-tools#downloads)
